# How to Run 🏃‍♂️

Follow the steps below to run this project locally using PHP’s built-in development server.

## Step 1: Open the Project Folder
Open **Command Prompt (CMD)** and navigate to the project directory.

Example:
```bash
cd C:\path\to\your\project
```

## Step 2: Start the PHP Development Server
Run the following command to start the local PHP server:
```bash
php -S localhost:8000
```

## Step 3: Open the Application in Browser
Open your browser and access the application at:
```
http://localhost:8000/index.php
```


# Or just use the server.bat as its already has the script to run these

---

✅ Make sure **PHP is installed** and added to your system PATH before running the server.
